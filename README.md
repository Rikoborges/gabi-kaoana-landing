# 🍰 Gabi Kaoana – Landing Page

Site institucional e moderno para apresentar os produtos e delícias da Gabi Kaoana, confeitaria artesanal em Curitiba.

## 🚀 Funcionalidades

- Landing page leve, responsiva e bonita
- Menu adaptável para mobile
- Cards de produtos e depoimentos
- Botão direto para WhatsApp
- Footer com mapa, termos e redes sociais
- Modais para políticas do site

## 🖥️ Tecnologias

- HTML5
- CSS3 (com variáveis e responsividade)
- JavaScript puro (vanilla JS)
- SVG para logo leve
- Compatível com deploy no **Vercel** ou **GitHub Pages**
